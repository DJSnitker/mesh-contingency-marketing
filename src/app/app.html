How it works

One node bridges the mesh to the world

A small computer with a MeshCore companion radio on USB runs the node. It listens for direct messages, runs the command, and replies over the mesh. When the internet is reachable from the node, it fetches weather and sends email for people who can’t.

Sealed messages

Private, even from the node’s owner

Set a passphrase and every new message to you is sealed. The node stores only who sent it and when; nobody can read it without your passphrase. Nobody has to handle keys.

  • Your passphrase becomes a key pair (scrypt, then X25519). Only the public half is saved.
  • The passphrase and private half are never stored: inbox <passphrase> rebuilds the key, opens your messages and forgets it again.
  • Private commands never echo the message, passphrase or reply to the node’s console.

A forgotten passphrase can’t be recovered, and messages sealed with it are lost. Sealing protects what’s stored; the radio still hands the node plain text as each message arrives.

Commands

32 commands, one direct message away

Command names are case-insensitive. Long replies arrive as numbered parts, at most 8. Commands are plugins, so new ones can be written and installed as separate packages.

Run your own node

Put a node on your mesh

All it takes is a computer that stays on and a MeshCore companion radio on USB serial. The Bible is bundled, so verse works offline; weather uses the National Weather Service with no API keys.

  • Python 3.11 or newer
  • A MeshCore companion radio on USB serial
  • The mail command, for email
  • Internet on the node for wx and email
Setup instructions Run as a service
setup.sh
# install
python3 -m venv .venv
.venv/bin/pip install -e .

# configure commands, users and admins
cp config.example.toml config.toml
cp users.example.toml users.toml
chmod 600 config.toml users.toml

# config.toml: who can run what
[commands]
wx      = {{ '{' }} permission = "public" {{ '}' }}
msg     = {{ '{' }} permission = "user" {{ '}' }}
approve = {{ '{' }} permission = "admin" {{ '}' }}
